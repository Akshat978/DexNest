# `@dexnest/dev-intelligence-contracts`

Types and pure functions shared by Developer Intelligence and Standup: the
domain model (repositories, snapshots, TODOs, technologies, health checks, scan
runs), the developer event envelope and fingerprints, the persistence ports,
and the Standup report and issue-lifecycle contracts.

No I/O. Imported by `@dexnest/dev-intelligence`, `@dexnest/standup` and
`@dexnest/dev-intelligence-store`.
